# HCI Design Portfolio

A design repository for my **Human Computer Interaction (HCI)** course. It stores the design artefacts produced each week — wireframes, prototypes and usability evaluation reports — so the full design process, from first sketch to evaluated redesign, is recorded in one place.

## What's inside

```
hci-design-portfolio/
├── README.md
├── report/                → weekly assignment reports
├── evaluation-reports/    → usability evaluations of real products (with screenshots)
└── wireframes/            → low-fidelity wireframes (SVG — drag straight into Figma)
```

## Tools

- **Figma** (free Starter plan) — wireframing and prototyping
- **Nielsen's 10 usability heuristics** — evaluation method
- **GitHub** — versioned storage for all design artefacts

## Method in one line

Design is a cycle, not a straight line: **research → design → prototype → evaluate → refine** — and the user stays at the centre of every step.
