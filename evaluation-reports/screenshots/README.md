# Screenshots to attach (evidence for the evaluation report)

Take these three screenshots of the UAF LMS and save them in this folder with these names:

| File name | What to capture | Which flaw it proves |
|---|---|---|
| `01-login-page.png` | The full login page at `lms.uaf.edu.pk/login` | Flaws 2, 3, 4 — Login + Result boxes mixed, "Recover your Account", "Cookies must be enabled" warning |
| `02-blocked-access-banner.png` | A close-up of the banner *"Student Login Access is blocked till result submission."* | Flaw 1 — whole-portal block with no date or reason |
| `03-not-secure-http.png` | The browser address bar showing `http://lms.uaf.edu.pk` and the "Not secure" warning | Flaw 5 — unencrypted login page |

How: open the page → press `Win + Shift + S` (Windows) → drag over the area → paste into Paint → Save As PNG with the file name above.
